# Oś czasu ESG

Statyczna strona z osią czasu regulacji ESG. Cała strona, z danymi i czcionkami, jest w pliku `index.html`.

## Vercel

1. W Vercel wybierz **Add New → Project** i zaimportuj to repozytorium.
2. Framework Preset: **Other**. Build Command i Output Directory zostaw puste.
3. Kliknij **Deploy**.

Podgląd lokalny:

```bash
python3 -m http.server 3000
```
